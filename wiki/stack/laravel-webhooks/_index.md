# Laravel Webhooks — the reference corpus

Deep reference behind **[[fleet-webhook-specification]]** (the rule of record — read that first;
these pages carry the mechanics, evidence, and worked examples). Ratified 2026-08-08 from a
maintainer interrogation plus industry prior art: Stripe (the explicit DX and documentation bar),
GitHub, and Svix. The corpus documents the fleet's outbound webhook management system — an
opt-in capability: no app is forced to ship webhooks, but any app that does builds them this
way. Runnable artifacts land later as the opt-in bundle at
[`standards/laravel/webhooks/`](../../../standards/laravel/webhooks/) (bundle, future pass).
The management API conforms to [[fleet-api-specification]]; its own corpus is
[laravel-rest-api](../laravel-rest-api/_index.md).
