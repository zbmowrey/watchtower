# The CRO Operating Loop

Use this to improve conversion without random page changes.

## Do

- Research the conversion path.
- Convert observations into insights.
- Write hypotheses.
- Prioritize by impact, confidence, and effort.
- Choose test, ship, or research.
- Log every change and result.
- Reuse learnings across similar pages.

## When

- When a conversion stage is the active constraint.
- Before redesigning a money page.
- After launch traffic starts.
- When analytics shows drop-off but the cause is unclear.

## How

1. Gather quantitative data: funnel, heatmaps, forms, recordings, page speed, search queries.
2. Gather qualitative data: surveys, interviews, support, sales calls, reviews.
3. List friction points by page section and user intent.
4. Write hypotheses:
   - Because `[evidence]`
   - Changing `[element]`
   - For `[audience]`
   - Will move `[metric]`
5. Score ideas.
6. Decide:
   - Test if sample supports it.
   - Ship if evidence is strong and traffic is low.
   - Research if cause is unknown.
7. Measure after the window.
8. Record decision.

## Watch

- Sample too small for testing.
- Multiple changes with no attribution.
- Traffic mix changing during readout.
- Form or analytics bugs.
- Novelty effects.
- Segment-specific wins hidden by aggregate metrics.

## Avoid

- Redesigning from taste.
- Testing low-impact visual changes while core offer is unclear.
- Calling inconclusive tests wins.
- Peeking and stopping early.
- Running CRO without an owner metric.
