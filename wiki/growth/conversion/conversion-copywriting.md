# Conversion Copywriting

Use this to write page, CTA, form, email, and paywall copy from customer language.

## Do

- Collect voice-of-customer input.
- Classify awareness stage.
- Build message hierarchy.
- Write the value proposition.
- Convert features into outcomes.
- Use specific CTAs.
- Add microcopy at anxiety points.
- Pass public copy through house-style review where required.

## When

- Before landing-page rewrite.
- Before paid ads.
- Before onboarding/paywall copy.
- Before pricing or offer pages.
- When users misunderstand the product.

## How

1. Mine calls, support, reviews, surveys, sales notes, and search queries.
2. Extract pains, desired outcomes, alternatives, objections, and exact phrases.
3. Pick awareness stage.
4. Write hierarchy:
   - Primary promise.
   - Supporting proof.
   - Mechanism.
   - Objections.
   - CTA.
5. Draft headlines and CTAs.
6. Replace abstract claims with concrete outcomes.
7. QA readability and specificity.

## Watch

- Words customers never use.
- Claims with no proof.
- CTA ambiguity.
- Copy aimed at the wrong awareness stage.
- Jargon above the fold.
- Microcopy missing near price, privacy, card, or cancellation anxiety.

## Avoid

- Starting from frameworks instead of VoC.
- Writing for multiple ICPs at once.
- Using clever headlines before clear ones.
- Making CTAs describe effort instead of outcome.
- Testing copy before traffic and measurement support it.
