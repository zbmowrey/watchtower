# Forms & Signup Flow

Use this to reduce friction between intent and first value.

## Do

- Ask only for fields needed for the next step.
- Use persistent labels.
- Validate inline.
- Use mobile-native input types.
- Preserve user input on errors.
- Offer SSO when it reduces friction for the audience.
- Use progressive profiling after signup.
- Track field-level drop-off.
- Hand users directly into activation.

## When

- Before acquisition.
- When page visits do not become leads/signups.
- When mobile conversion is weak.
- When checkout or account creation has high abandonment.
- Before adding qualification fields.

## How

1. Define the next required action.
2. List required data for that action only.
3. Remove or defer all other fields.
4. Choose single-step or multi-step:
   - Single-step for simple, low-friction signup.
   - Multi-step for high-commitment flows where first step is easy.
5. Add validation and error states.
6. Add trust microcopy near sensitive fields.
7. Track start, field focus, field error, submit, success, and abandonment.
8. Route success to first-run action.

## Watch

- Phone, company size, role, budget, and card fields.
- Email verification before value.
- CAPTCHA false positives.
- Password rules causing abandonment.
- Mobile keyboard mismatch.
- Hidden required fields.

## Avoid

- Placeholder-only labels.
- Asking for sales qualification before basic lead capture.
- Sending new users to a blank dashboard.
- Adding card-upfront without a clear quality/payback reason.
- Treating form completion as activation.
