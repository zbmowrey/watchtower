# Content Production & E-E-A-T

Use this to produce search assets that match intent and add unique value.

## Do

- Start with a SERP-driven brief.
- Capture consensus coverage.
- Add information gain.
- Add experience, expertise, author, proof, and update signals.
- Use AI only within quality policy.
- Run pre-publish QA.
- Assign distribution and monitoring.

## When

- After keyword, intent, and topical mapping.
- Before publishing BOFU, cluster, comparison, integration, glossary, or local pages.
- When refreshing decayed content.

## How

1. Record target query, cluster, intent, and conversion path.
2. Review top-ranking pages.
3. List required subtopics.
4. Add at least two information-gain elements.
5. Draft outline.
6. Add proof, screenshots, examples, data, quotes, or first-party experience.
7. Write and edit.
8. QA title, H1, URL, schema, links, images, CTA, and analytics.
9. Publish and distribute.

## Watch

- Rewritten consensus with no new value.
- Unsupported claims.
- Missing author or update signals where trust matters.
- AI text that adds generic filler.
- Content that has no conversion path.

## Avoid

- Producing content before intent is known.
- Chasing word count.
- Publishing at scale without QA.
- Using AI to create unverifiable claims.
- Treating publication as the end of the asset lifecycle.
