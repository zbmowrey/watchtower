# Site Architecture & Internal Linking

Use this to organize URLs and move authority toward important pages.

## Do

- Design stable, descriptive URLs.
- Keep important pages shallow.
- Link cluster pages to pillars and money pages.
- Use navigation and footer links deliberately.
- Control faceted navigation.
- Detect orphan pages.

## When

- Before building content clusters.
- Before pSEO.
- Before redesigns or migrations.
- When important pages are buried.
- When cannibalization or orphaning appears.

## How

1. List money pages.
2. Map supporting clusters.
3. Define URL patterns.
4. Set click-depth targets.
5. Add hub, sibling, and parent links.
6. Configure facets, filters, and pagination.
7. Crawl for depth, orphans, redirects, canonicals, and duplicates.
8. Fix links by template where possible.

## Watch

- Money pages with few internal links.
- Blog posts isolated from product pages.
- Facets creating infinite URLs.
- Pagination hiding content.
- Footer links diluted across too many targets.
- URL changes without migration plan.

## Avoid

- Designing IA from org chart alone.
- Creating deep paths for high-value pages.
- Linking only chronologically.
- Allowing filters to index by default.
