# Programmatic SEO

Use this to create data-driven page sets only when each page can be useful and unique.

## Do

- Prove inventory exists.
- Prove search demand exists.
- Define page template and unique data.
- Set quality gates.
- Stage indexation.
- Monitor coverage, indexation, traffic, conversion, and maintenance load.

## When

- After editorial trust exists.
- When many pages share a repeatable intent.
- For integrations, comparisons, calculators, locations, glossaries, or data pages.
- When unique data or utility exists per page.

## How

1. Define page type and intent.
2. Validate keyword pattern.
3. Validate data source.
4. Build sample pages manually.
5. QA uniqueness, utility, links, schema, and conversion path.
6. Release a small batch.
7. Monitor indexation and quality.
8. Expand only if signals pass.

## Watch

- Thin or near-duplicate pages.
- Empty data states.
- Crawled-not-indexed patterns.
- Faceted index bloat.
- Template errors at scale.
- No conversion path.

## Avoid

- Scaling pages before quality gates.
- Generating text-only variants with no unique value.
- Indexing every possible combination.
- Treating pSEO as an early substitute for authority.
